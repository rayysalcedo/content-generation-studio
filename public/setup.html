Connect a sub-account.

Install the Course Studio app on a CC360 sub-account so the tool can push courses and upload media there. Each sub-account installs once — after that, anyone with the form URL can generate courses for it.

Install on a sub-account

You'll be redirected to GoHighLevel. Sign in as a user with admin access to the sub-account, choose the sub-account from the list, and approve the requested permissions. You'll come back here once it's installed.
